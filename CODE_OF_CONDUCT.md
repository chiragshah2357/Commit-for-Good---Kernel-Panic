# Code of Conduct

## Our standard

This project welcomes contributors of every background and experience level. To keep it a good place to work:

- Be respectful and assume good faith.
- Give and accept feedback on the work, not the person.
- Welcome questions from newcomers; this project exists so others can learn from it and build on it.
- Credit other people's work and be honest about what is real, generated, borrowed or unfinished.

Not acceptable: harassment, discrimination, personal attacks, trolling, publishing someone's private information,
or any conduct that would be inappropriate in a professional setting.

## Scope

This applies to all project spaces: issues, pull requests, discussions and comments.

## Enforcement

Maintainers may edit or remove comments, close issues or pull requests, and block contributors who do not follow
this code. To report a problem, contact the repository owner through GitHub (https://github.com/chiragshah2357), or
open an issue if the matter is not sensitive.

This code of conduct is a short, plain-language statement written for this project. It is inspired by the
widely used Contributor Covenant (https://www.contributor-covenant.org/), which you may prefer to adopt in full
as the project grows.
